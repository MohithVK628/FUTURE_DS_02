# Task 2: Social Media Campaign Performance Dashboard

## Internship
Data Science & Analytics Internship – Future Interns

## Objective
Analyze social media campaign data to evaluate performance based on spend, revenue, ROI, CTR, and platform effectiveness.

## Dataset
- Platform (Facebook, Instagram)
- Campaign Name
- Impressions
- Clicks
- Spend
- Conversions
- Revenue
- Date

## Tools Used
- Power BI
- MS Excel

## Key KPIs
- Total Spend
- Total Revenue
- CTR (%)
- CPC
- ROI (%)

## Dashboard Features
- Campaign-wise revenue and spend comparison
- Platform-wise performance analysis
- CTR trend over time
- Interactive slicers (Date, Platform, Campaign)

## Key Insights
- Identified high ROI campaigns
- Compared Facebook vs Instagram performance
- Analyzed efficiency using CTR and CPC
- Tracked trends using time-based analysis
